Zadanie 21 - Użycie ID

Pojęcie Znaczenie pojęcia
Co znaczy skrót ID? ID oznacza identyfikator elementu w języku HTML.
Jaki jest cel stosowania ID? ID służy do wyróżnienia jednego konkretnego elementu na stronie.
Jakie jest znaczenie znaku # ? Znak # w CSS oznacza odwołanie do identyfikatora elementu.
Jak następuje wywołanie ID? Wywołanie ID odbywa się za pomocą atrybutu id, np. <p id="przyklad">Tekst</p>. W arkuszu CSS używa się zapisu #przyklad.
Uwagi na temat stosowania ID
  • ID powinno być unikalne na stronie.
  • Jedno ID można przypisać tylko do jednego elementu.
  • ID pozwala łatwo formatować wybrany element.
